# Optical Quantum Teleportation System Model

This folder contains the reconstructed optical quantum teleportation circuit model.

## Components included

- Laser source
- Neutral Filter (NF)
- Half-Wave Plate (HWP)
- Quarter-Wave Plate (QWP)
- Polarizing Beam Splitter (PBS)
- Mirrors
- CNOT operation region
- Coupling region
- Measurement stage

The circuit visualization was generated using Python Matplotlib 3D.
